# 研究协作约定示例

## 资料与证据

- 先读取当前项目的研究问题、资料索引和实验约定。
- 区分原材料、文献结论、实验观察、AI 推断和研究者决定。
- 论文引用核实 DOI；尚未分配时说明状态并保留稳定标识。
- AI 新建笔记标记为 pending，经研究者核对后再更新审阅状态。

## 研究与实验

- 每次实验说明它要检验什么，以及不同结果将怎样影响下一步。
- 记录数据划分、配置、代码版本和结果来源。
- 评价设置按项目约定选择并冻结，保留测试数据的独立用途。
- 结论与证据对应，遇到反证时更新解释和适用边界。

## 成品与协作

- 成品描述当前采用的研究问题、方法、结论和验证结果。
- 项目路径、数据权限、运行命令和机器资源放在项目配置中维护。
- 依据具体任务选择技能，保留研究者对方向和投入的判断。
