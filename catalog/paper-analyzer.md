# paper-analyzer

独立论文深度解读。

| 项目 | 说明 |
|---|---|
| 流程位置 | 输入 |
| 使用建议 | 按需 |
| 输入 | PDF、论文链接或全文 |
| 输出 | 方法、公式、实验、代码与局限分析的 Markdown 主稿 |
| 依赖 | PDF 与网页读取；需要代码分析时使用 Git；HTML 交给 md-to-html |
| 来源 | [上游来源](https://github.com/zsyggg/paper-craft-skills) |
| 许可 | 上游 README 声明 MIT；包内附 MIT 文本及来源记录，上游未提供独立 LICENSE 文件。 |
| 快照日期 | 2026-09-27 |

## 安装

[下载完整安装包](../packages/paper-analyzer.zip)

下载仓库后，也可运行：

```bash
python scripts/install_skill.py paper-analyzer
```

ZIP 的顶层目录是 `paper-analyzer/`，保留原技能的 SKILL.md、脚本、参考文件、模板和资源。完整文件清单可直接查看 ZIP 内容。
