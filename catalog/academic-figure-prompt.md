# academic-figure-prompt

学术图形英文生图提示词。

| 项目 | 说明 |
|---|---|
| 流程位置 | 输出二 |
| 使用建议 | 按需 |
| 输入 | 论文内容、图形需求与配色偏好 |
| 输出 | 可交给图像工具的详细英文提示词 |
| 依赖 | 提示词阶段不需 API；图像生成由选定服务完成 |
| 来源 | 本地维护版本 |
| 许可 | 本地维护快照；原目录未单独声明许可证，上游来源与开放许可待维护者补充。 |
| 快照日期 | 2026-09-27 |

## 安装

[下载完整安装包](../packages/academic-figure-prompt.zip)

下载仓库后，也可运行：

```bash
python scripts/install_skill.py academic-figure-prompt
```

ZIP 的顶层目录是 `academic-figure-prompt/`，保留原技能的 SKILL.md、脚本、参考文件、模板和资源。完整文件清单可直接查看 ZIP 内容。

## 使用

在 Codex 中按名称选择 `academic-figure-prompt`，提供表中列出的输入，并说明期望成品。
