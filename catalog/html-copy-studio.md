# html-copy-studio

演示文案与视觉构思工作台。

| 项目 | 说明 |
|---|---|
| 流程位置 | 输出二 |
| 使用建议 | 按需 |
| 输入 | 逐页文案、演讲稿和可选配图构思 |
| 输出 | 可逐节复制的 HTML 与 Markdown 主稿 |
| 依赖 | Node.js 与 marked；脚本支持 --modules-dir 指定模块目录 |
| 来源 | 本地维护版本 |
| 许可 | 本地维护快照；原目录未单独声明许可证，上游来源与开放许可待维护者补充。 |
| 快照日期 | 2026-09-27 |

## 安装

[下载完整安装包](../packages/html-copy-studio.zip)

下载仓库后，也可运行：

```bash
python scripts/install_skill.py html-copy-studio
```

ZIP 的顶层目录是 `html-copy-studio/`，保留原技能的 SKILL.md、脚本、参考文件、模板和资源。完整文件清单可直接查看 ZIP 内容。
