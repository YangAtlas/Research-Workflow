# clarify-research-idea

任务、假设与方法方案澄清。

| 项目 | 说明 |
|---|---|
| 流程位置 | 输出一 |
| 使用建议 | 主力 |
| 输入 | 初步问题、相关文献与资源条件 |
| 输出 | 任务定义、研究定位、核心假设、方法结构与验证线索 |
| 依赖 | 文献检索；图形规划使用 Mermaid 等可用工具 |
| 来源 | 本地维护版本 |
| 许可 | 本地维护快照；原目录未单独声明许可证，上游来源与开放许可待维护者补充。 |
| 快照日期 | 2026-09-27 |

## 安装

[下载完整安装包](../packages/clarify-research-idea.zip)

下载仓库后，也可运行：

```bash
python scripts/install_skill.py clarify-research-idea
```

ZIP 的顶层目录是 `clarify-research-idea/`，保留原技能的 SKILL.md、脚本、参考文件、模板和资源。完整文件清单可直接查看 ZIP 内容。

## 使用

在 Codex 中按名称选择 `clarify-research-idea`，提供表中列出的输入，并说明期望成品。
