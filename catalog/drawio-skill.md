# drawio-skill

可编辑方法图与系统结构图。

| 项目 | 说明 |
|---|---|
| 流程位置 | 验证 |
| 使用建议 | 主力 |
| 输入 | 关系、结构、流程或现有图 |
| 输出 | .drawio 文件及 PNG/SVG/PDF 等导出 |
| 依赖 | 图片/PDF 导出需要 draw.io Desktop；自动布局按需使用 Graphviz；部分脚本需要 Python |
| 来源 | [上游来源](https://github.com/Agents365-ai/drawio-skill) |
| 许可 | MIT；图形索引的 Apache-2.0 声明和许可随包保留。 |
| 快照日期 | 2026-09-27 |

## 安装

[下载完整安装包](../packages/drawio-skill.zip)

下载仓库后，也可运行：

```bash
python scripts/install_skill.py drawio-skill
```

ZIP 的顶层目录是 `drawio-skill/`，保留原技能的 SKILL.md、脚本、参考文件、模板和资源。完整文件清单可直接查看 ZIP 内容。

## 使用

在 Codex 中按名称选择 `drawio-skill`，提供表中列出的输入，并说明期望成品。

## 版本

本包保留本地 2.1.0。按实际图示需求决定是否采用上游更新。
